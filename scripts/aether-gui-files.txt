# The AetherRX page family: the files scripts/sync-aether.sh copies from AetherSDR's
# src/gui/ into vendor/aethersdr/src/gui/, unmodified. One path per line, relative to
# src/gui/. Lines starting with # are comments. CMake builds every .cpp listed here.
#
# How this list was made: start from the seven stage panels (Strip{Gate,Eq,Comp,Tube,
# Pudu,RxOutput,Waveform}Panel), the rail (StageTabBar) and the page wrapper (StagePage),
# follow every quoted #include, and take each reached header's .cpp along with it.
# FramelessResizer is a root of its own: nothing here includes it, but the custom frame
# of Windows and Linux (src/gui/shell/WindowChrome.cpp) uses its resize edges, and
# FramelessMoveHelper.h to move the window by its header.
#
# Left out on purpose: AetherRxDialog, AetherRxSettingsDialog, AetherDspWidget and
# CanonWindow (never opened here; CanonWindow needs Qt 6.12), and NrGainStrip, which
# is forked into src/gui/aether/fork/ because it uses Qt 6.6 API. ClientEqApplet.h and
# PanadapterMessageOverlay.h are headers only: what is used from them is an enum and a
# plain struct, and their .cpp files would bring whole widgets nobody shows.
#
# To change it: edit this list, run sync-aether.sh (its include check names anything
# still missing), and build against Qt 6.4.2.
